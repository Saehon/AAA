# validate-data
Check tabular schema, required fields, key uniqueness and structural missingness; report sample grain, reporting dates, currency, source rights, duplicates and unresolved source discrepancies. Code verifies structure, not underlying filing truth.

Mandatory: public-data-privacy-gate; independently inspected source when citing; human reviewer-engineer release gates; no restricted/personal/client data, secret retrieval, trading, posting, SOX assurance, live connectors, or fabricated execution.
