# Public company claim check
1. Reject personal, confidential, licensed-restricted, client and private research data before analysis; never seek private credentials.
2. Locate public original filing when supported, specifying issuer, fiscal period, currency, GAAP/IFRS metric, source URL, page and date. Do not treat an uninspected URL as verified evidence.
3. Compare like periods and units; never confuse adjusted EBITDA with audited net income or infer a fraud finding from an arithmetic anomaly.
4. Independently recompute numerical changes if a deterministic executable tool is available; otherwise mark NOT EXECUTED.
5. Report verified against inspected source, arithmetic contradiction, insufficient evidence, or not checked—without a numerical trust score absent calibration.
6. Include a short beginner explanation, evidence table, unresolved contradictions and human review next step.
