# sox-testing
Reproducible synthetic sample plans, educational control workpapers, exceptions and reviewer signoff. Control deficiency, significant deficiency and material weakness are NOT automatically classified. Require completeness evidence and do not interpret sample pass as audit opinion.

Mandatory: apply public-data-privacy-gate, preserve source/period/currency, use synthetic/public examples only, never access private or vendor-licensed datasets, never certify audit/SOX/IFRS outcomes, and route consequential conclusions to reviewer-engineer. Calculations are only executed when an actual deterministic runtime returns results.
