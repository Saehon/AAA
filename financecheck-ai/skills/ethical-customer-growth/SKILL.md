# ethical-customer-growth

Use TikTok/Instagram-inspired clarity, relevance, accessible visual storytelling and easy sharing, not reward loops or time-on-site maximization. Ask for user's optional level/interest only when it materially helps, provide a neutral default, and never infer sensitive traits.
Primary KPI: proportion of users completing a meaningful finance understanding/verification task with correct, evidence-grounded output. Guardrails: hallucinated sources, unsupported verified claims, miscomprehension, privacy incidents and user regret. Secondary: 30-second task usefulness, quiz delta, optional shares, opt-in week-1 return.
A/B testing: preregister a 2x2 experiment (short vs detailed default; static card vs brief explanation); hold user population, time window, metric definitions and risk thresholds fixed. Never claim causal improvement or conversion without observed event data and correct denominator. Document consent, event minimization and retention.
