# FinanceCheck AI V3 — Public GitHub source notice

The GitHub repository distributes original financial-literacy skill definitions, Claude command templates, user-experience instructions, and a small independent offline MCP reference server with its own synthetic unit tests.

**Not distributed on GitHub:** the privately developed V2.2 financial calculation engine, private engine tests, licensed professional standards, restricted vendor data, personal client records, and unpublished/patent-sensitive POMELO, VERA, DARWIN or KIWI research mechanisms.

The public reference server implements only three bounded tools using caller-supplied public/synthetic figures and general finance explanations. It **does not authenticate filings, fetch SEC data, host HTTPS endpoints, provide investor advice or certify SOX controls**. GitHub publication does not imply ChatGPT or Claude directory approval.

The source contribution is offered under the repository's existing Apache-2.0 license only insofar as the licensor has authority to grant rights. Institutional/coauthor and patent rights still require review. Independent engineering and security testing is required before deployment.
