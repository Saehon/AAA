# V3.4 source hierarchy and legal guardrails

1. **Official binding authority**: relevant legislation, effective IFRS/ISSB/ESRS/IFRIC, PCAOB/IAASB standards, local adoption; inspect exact version.
2. **Professional ethical/practice authority**: ACCA, AICPA, IIA, IMA, ACFE, CIMA, ICAEW, IESBA, IFAC, ISACA; rules apply to the appropriate members/engagements, not every company.
3. **Big Four interpretative commentary**: PwC Viewpoint, EY International GAAP, KPMG IFRS Toolkit, Deloitte IAS Plus; no proprietary manual redistribution or endorsement.
4. **Primary research evidence**: SEC EDGAR, official report HTML/XBRL and company statement; DOI/journal documents; code/data only with provenance and licences.
5. **Research leads**: SSRN/thesis/metadata indexes, GitHub, Hugging Face, Kaggle; discovery ≠ data validation, licence, executed replication, peer review or funding eligibility.

For each requested answer, return an evidence ledger (claim, issuer, source URL, inspected yes/no, effective date, jurisdiction, version, license, source excerpt or fact, human review, limits). If no live source was inspected, cite only conceptual resource links and label conclusions **not independently verified**. Never use credential names to suggest endorsement.
