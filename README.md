## Purpose

AAA is an experimental laboratory for studying how AI can support accounting and auditing while preserving evidence quality, provenance, reproducibility, professional skepticism, uncertainty disclosure, and human judgment.

The repository is a **supporting laboratory within the NAAIL research portfolio**. Stable flagship architectures and project-level documentation are maintained through NAAIL OpenLab; AAA is used for notebooks, prototypes, empirical experiments, and teaching/research demonstrations.

## Scientific workflow

AAA experiments should follow the NAAIL evidence-governed workflow:

**Research Question → Literature Validation → Competing Hypotheses → Multi-Agent Critique → Empirical Design → Computational Test → Adversarial Review → Robustness/Falsification → Reproducibility → Human Gate**

AI output is not treated as scientific or professional evidence by itself. Claims require traceable data, appropriate methods, reproducible analysis, and human review.

AAA provides experimental infrastructure that can support:

AAA does not expose private POMELO code, patent-sensitive architecture, confidential datasets, restricted standards content, or third-party proprietary audit methodologies.

## Reproducibility target

New AAA studies should progressively adopt this structure:

```text
study/
├── README.md
├── data_manifest/
├── notebooks/
├── src/
├── tests/
├── configs/
├── results/
└── run_manifest.json
```

Each empirical study should document data origin, transformations, exclusions, variables, model specifications, evaluation metrics, robustness tests, software environment, random seeds where relevant, and known limitations.
