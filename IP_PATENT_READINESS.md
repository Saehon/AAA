## Core rule

A GitHub commit can provide a dated technical record, but it **does not create patent rights, reserve patentability, or substitute for filing a patent application**. Public disclosure can affect novelty and patentability depending on jurisdiction and timing.

Potentially patentable implementation details should therefore remain private until an explicit IP review and release decision has been completed.

## Pre-publication invention gate

Before publishing a new algorithm, scoring method, agent workflow, architecture, benchmark, digital-twin mechanism, verification method, or other potentially protectable contribution:

1. record inventors, conception date, problem, technical contribution, alternatives, experiments, diagrams, and source-commit hashes;
2. conduct a prior-art and scientific-literature search;
3. separate third-party/open-source material from original contribution;
4. mark the work **PRIVATE — PATENT REVIEW PENDING**;
5. obtain qualified patent/legal review when protection is contemplated;
6. choose explicitly among patent filing first, trade-secret/private R&D, defensive publication, or public research release;
7. publish only after that decision.
