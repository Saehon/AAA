# Security Policy

AAA is a public research laboratory. Do not place confidential client information, credentials, access tokens, private keys, restricted professional materials, or sensitive institutional data in this repository.

## Reporting

Do not disclose exploitable vulnerability details in a public issue. Use GitHub private security reporting where available or another appropriate private channel to the repository owner.

## Research-data safeguards

- use synthetic, public, or appropriately licensed data for public examples;
- document data provenance and rights;
- remove secrets and personal/confidential information before committing files;
- treat prompts, logs, embeddings, vector stores, model outputs, and generated reports as potentially sensitive when they contain source material;
- review external API/model-provider data-retention terms before use;
- do not use public notebooks as a substitute for production security controls.

## Production boundary

Repository code and notebooks are research artifacts. Real accounting or audit use requires independent security, privacy, legal/regulatory, model-risk, and professional review.
